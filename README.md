# SolaX Local Control for Home Assistant

A small custom Home Assistant integration for direct local control of a
SolaX X1-BOOST-5K-G4 through a Pocket WiFi 3.0 dongle. It does not use SolaX
Cloud and continues to work when the internet is unavailable.

This is an independent project, not an official SolaX product.

## Current scope

The integration polls the dongle every 15 seconds and provides:

- inverter AC output power;
- combined and per-string PV power;
- AC voltage, current, and frequency;
- energy today and total energy;
- inverter operating state;
- read-only export-control mode and user-value diagnostics; and
- an **Output limit** number entity that controls the whole-inverter active
  power cap from 0% to 100%.

Only the output-percentage write is exposed. Changing CT/meter direction,
country/grid protection settings, export-control mode, and soft/hard export
limits is intentionally out of scope because those values affect electrical
compliance and have not been safely verified for automation.

The write path checks the dongle acknowledgement and immediately reads the
setting back. Home Assistant reports an error if the readback does not match.

## Supported hardware

The response and write-register layout has been verified on:

- SolaX X1-BOOST-5K-G4 (device type 18, inverter serial prefix `XB4050`)
- SolaX Pocket WiFi 3.0

Setup deliberately refuses other inverter layouts. Additional models should
only be added after confirming both their live-data indexes and their local
HTTP write-register map.

## Installation

### HACS custom repository

1. Upload this repository to GitHub.
2. In HACS, add its GitHub URL as a custom repository of type **Integration**.
3. Download **SolaX Local Control** and restart Home Assistant.
4. Go to **Settings > Devices & services > Add integration** and search for
   **SolaX Local Control**.
5. Enter the dongle's fixed LAN IP address and local password. The password is
   normally the registration number printed on the dongle label.

### Manual installation

Copy `custom_components/solax_local` into the `custom_components` directory in
your Home Assistant configuration, restart Home Assistant, and add the
integration through the UI.

## Network notes

- Give the dongle a DHCP reservation so its IP address does not move.
- Home Assistant must be able to make HTTP requests to the dongle on port 80.
- Do not expose the dongle's web interface to the internet.
- The local password is stored in Home Assistant's config entry storage and is
  never added to entity attributes or logs by this integration.

## Automation example

The number entity accepts a percentage, not watts. For example:

```yaml
action: number.set_value
target:
  entity_id: number.solax_x1_boost_5k_g4_output_limit
data:
  value: 60
```

Entity IDs are generated by Home Assistant and may differ slightly. Use the
entity selector in the automation editor rather than relying on this example's
exact ID.

## Safety and recovery

The inverter retains the last output limit. An automation should explicitly
restore 100% when curtailment is no longer needed, and should include sensible
minimum/maximum limits and stale-sensor handling. This integration does not
change the inverter's certified grid-protection or export-control settings.
